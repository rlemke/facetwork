Method. FiveThirtyEight’s published NFL Elo without its quarterback adjustment: home field worth {{ (meta.params.hfa if meta.params else 48)|round|int }} rating points, {{ (meta.params.bye_bonus if meta.params else 25)|round|int }} for coming off a bye, a margin-of-victory multiplier damped for favourites, playoff differences scaled by {{ meta.params.playoff_mult if meta.params else 1.2 }}, and {{ ((meta.params.regress if meta.params else 0.4) * 100)|round|int }}% regression to the mean between seasons. 25 rating points = 1 point on the scoreboard. The constants were chosen on 2005–2014 and are reported from 2015 on, so these numbers are out of sample.

Two different records. The backtest re-scores history game by game using only results before each game. The live record uses predictions stored before kickoff and never rewritten, so it cannot benefit from anything learned afterwards. The betting line is converted to a probability with a 13.45-point standard deviation around the spread.

Known limit. The model cannot see quarterback changes, injuries, weather or coaching. When it and the line disagree by more than a few points, the line usually knows something the model does not.
